# ZSClip 1.0.11

- 修复 Windows 记录列表和托盘右键菜单切换选中项时的空白、闪动，保留菜单绘制状态并一次呈现完整菜单项。
- 修复选择自定义提示音文件时报 PowerShell 参数错误的问题，使用 Windows 原生文件选择框，支持中文路径和多种音频格式。
- 改善 Excel、WPS 表格的格式保留，支持字体颜色、粗细、字号、底色、边框和合并单元格；修复 Office 样式表注释及 WPS 片段起点偏移导致格式丢失的问题。
- 复制记录默认以卡片显示，Windows 卡片使用更清晰的间距、圆角边框和柔和阴影，改善不同缩放比例下的显示。
- 缺少富格式选项的旧配置默认启用“保留文本与表格格式”；已保存的开关选择保持不变。

卡片样式可在“设置 → 外观”调整；富格式采集可在“设置 → 剪贴板 → 保留文本与表格格式”开启。已保存为纯文本的历史记录需要重新复制才能保留源格式；纯文本粘贴功能继续移除格式。

Windows 提供普通版和无局域网版；macOS 提供 Apple Silicon 与 Intel 安装包；Linux 提供 x86_64 DEB 与压缩包。QQ 输入法桥接包沿用内部版本 `8.7.15-zsclip.8`。

Linux 全局快捷键和 VV 需要 X11；macOS 全局输入和粘贴需要辅助功能及输入监控权限。超级邮件合并、WPS 任务窗格和图片贴图使用 Windows 集成。
