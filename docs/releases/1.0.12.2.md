# ZSClip 1.0.12.2

本地修复候选版本，尚未公开发布。

- Windows VV 主窗改为复用双缓冲绘制。跨条目悬停不再把清空背景的中间帧直接绘制到屏幕；关闭窗口时释放缓冲。VV 触发、数字选择与输入清理规则保持原样。
- 富文本记录使用剪贴板的 Unicode 文本显示摘要和预览，移除新记录的 `HTML:` 前缀。旧富文本历史也从已保存的正文生成显示摘要，不改原始记录内容。
- Excel/Office 的文本与 HTML 作为并行格式处理，富文本记录保留原始制表符、空白格、换行和 Unicode 连接符。普通粘贴继续恢复支持的 HTML 格式与 Unicode 文本，纯文本粘贴仍使用文本。
- 读取剪贴板时，对短时占用做有界重试；序列号变化时终止旧读取，避免拼接两次复制的数据。
- issue #45 的截图显示的是“已写入剪贴板，但跨权限自动粘贴被 Windows 阻止”。输入权限检测改为完整性级别判断，并尊重 UIAccess。遇到权限阻止时，单独提供手动 Ctrl+V 和用户确认后的本次 UAC 重启入口；默认不提权，不更改开机启动或系统安全设置，不打开无关的窗口跳过设置。取消 UAC 时保留原进程。

验证记录、来源比较和未验证项见 [修复验证说明](../verification/1.0.12.2.md)。Windows 10 LTSC 2021 的实际桌面验收，以及 Excel、Word 与跨权限程序的真实交互矩阵仍需在对应机器上完成。
