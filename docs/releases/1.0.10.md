# ZSClip 1.0.10

Windows、macOS 与 Linux 配套版本。

## Windows

- 修复同一条目反复触发悬停加载时预览窗口闪动的问题，保留当前正文与滚动位置；超大预览会避开鼠标位置。
- 修复设置窗口关闭或最小化后未重新安排内存回收的问题；收起到托盘后释放隐藏窗口的缓存，迟到的缩略图和预览结果不再重新占用缓存。
- 可见的主窗口、设置及预览不会因后台回收被清空。托盘静置后的内存随系统及后台活动变化。
- 修复 Shift 切换输入状态时旧 VV 请求继续弹出或粘贴的问题；切换输入状态、窗口或输入框后取消过期操作。
- 区分输入法中文组合、英文及未知状态，英文与未知状态不发送模拟 Esc；取消 VV 不再向目标输入框补发 Esc。
- 改善微信输入框识别与候选选择粘贴，保留原输入目标、焦点及内容保护校验。

## macOS 与 Linux

- 设置按常规、外观、剪贴板、快捷键与 VV、分组、插件、同步、关于分为八页，支持内容字号、卡片显示及常用短语独立标题。
- 完善原生全局快捷键、VV 候选选择与目标窗口粘贴，补充长按、切换焦点和快捷键重新绑定的处理。
- 完善搜索、内容导出及原生编辑菜单。
- 同步凭据使用 macOS 钥匙串或 Linux Secret Service 保存；系统凭据库不可用时显示错误，不回退为明文保存。

Linux 全局快捷键要求 X11 桌面会话；VV 仅支持 X11 应用，原生 Wayland 全局输入尚不支持。macOS 全局输入与粘贴需要系统授予辅助功能及输入监控权限。

Linux 的 VV 输入触发保留两个 `v` 字符；全局快捷键可直接打开历史列表。超级邮件合并、WPS 任务窗格及图片贴图使用 Windows 集成。

Windows 提供普通版与无局域网版；macOS 提供 Apple Silicon 与 Intel 安装包；Linux 提供 x86_64 DEB 与压缩包。

QQ 输入法桥接包与桌面版配套提供，内部版本为 `8.7.15-zsclip.8`，局域网连接需使用含同步功能的普通版。不提供独立 Android 测试应用安装包。
