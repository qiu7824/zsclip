# ZSClip 1.0.12

## Windows：自定义标签与分类

- 默认提供“复制记录”和“常用短语”两个标签，可在“设置 → 分组 → 设计分类标签”中改名、新增、删除、排序或隐藏。
- 新建标签默认为**手动标签，内容为空**。在记录列表中单选或多选，再右键“添加到标签”，即可分类；同一条记录可加入多个标签。
- 手动标签支持文本、网址、图片、文件和常用短语，保留原记录的内容及类型，不复制一份历史数据，也不把图片或文件转换成文本短语。
- 右键“从标签移除”只解除所选分类关系；删除标签也不会删除原记录。标签内的“删除原记录（所有标签）”会删除原记录及其全部标签关联，操作含义与移出标签明确区分。
- 标签改名、排序和隐藏保持已有归属；数据库重新打开、粘贴后上移、重复记录合并时保留标签关联。
- **自动筛选**单独选择“自动筛选：复制记录”或“自动筛选：常用短语”，并设置分组、文件类型；自动视图按规则显示内容，不接受手动添加。
- 修复新复制内容绕过当前标签或类型筛选、直接混入列表的问题；切换标签、搜索和分页使用对应的分类条件。
- 标签整体居中，保持原有默认尺寸、圆角底色和选中高亮；窗口加宽后字号保持固定。标签较多时可通过右侧更多菜单切换，至少保留一个显示中的标签。
- 文本右键入口明确为“添加到常用短语”；图片和文件可通过手动标签分类管理。

## Windows：窗口与列表体验

- 支持拖动四边、四角调整宽度和高度，松开后自动保存；主窗口和快捷窗口共用记忆尺寸，重新打开或重启后恢复，并适配显示器缩放及可用屏幕范围。
- 内容区域随窗口宽度扩展，高度增加时显示更多记录；设置窗口中的旧草稿不会覆盖刚调整的尺寸。
- 同前缀网址按实际可用宽度显示原地址，便于查看文档编号和参数；已有历史记录同样适用，复制及粘贴使用完整原地址。
- 默认使用普通列表。卡片模式可在“设置 → 外观”中开启；已有明确保存的卡片开关保持原选择。
- 在“设置 → 外观 → 配置快捷按钮”中设置删除、置顶、编辑按钮的显示和顺序；按钮只作用于所在记录，编辑适用于文本及短语。
- 主界面保留原有记录图标，改善深浅主题适配；统一设置页及辅助窗口的按钮、开关、下拉框、输入框、列表边框与禁用文字，减少暗色界面的亮色残留和文字重影。
- 修复窗口置顶切换与实际窗口状态不一致的问题，并保留主窗口、快捷窗口各自的标签选择。

## Windows：便签插件

- 在“设置 → 插件”中开启便签，可管理多条本地便签；以首行为标题，编辑内容自动保存。
- 支持 `Ctrl+N` 新建、`Ctrl+S` 保存、`Ctrl+V` 粘贴，关闭窗口时保存当前内容。
- 在“快捷键与 VV”中将鼠标侧键绑定到便签，可弹出、聚焦或收起便签窗口。
- 保存失败或输入法仍在组合输入时保留编辑窗口，防止尚未保存的内容被关闭。
- 便签保存在数据目录的 `notes.sqlite3` 中，随数据目录迁移；不参与剪贴板 WebDAV 或局域网同步。关闭插件保留已保存的便签。

## 数据目录与 WebDAV

- 修复安装到受保护目录后 WebDAV 临时文件无法创建的问题；同步临时数据使用当前数据目录的临时子目录。
- Windows 可在“设置 → 关于”中更改数据目录；新目录须为空，重启时迁移并核对文件，原目录保留。
- 不再强制新建 D 盘数据目录，已有数据仍按兼容规则识别。
- WebDAV 请求凭据通过进程输入传递，避免在程序目录生成认证配置临时文件。
- 无局域网版本继续提供 WebDAV，同步与数据目录相关回归覆盖该构建配置。

## 绘制与内存回收

- 调整窗口尺寸时复用绘图缓冲区和行布局，减少重复分配、布局计算及未变化控件的更新。
- 隐藏或最小化窗口时释放本地绘图资源；其他面板仍可见时，保留其正在使用的共享资源。
- 修复贴边收起窗口仍被当作可见窗口、导致缓存回收未触发的问题，并处理收起后迟到的缩略图结果。
- 完善隐藏状态下的尺寸消息、托盘菜单关闭、后台任务完成及 VV 会话结束后的回收调度。
- 便签窗口关闭后释放编辑器和数据库连接。内存占用随活动窗口、内容和系统调度变化，不以固定的 0.1 MB 作为运行保证。

## 安装包与平台

- Windows x64：标准版、无局域网版安装包及对应便携包，另附资源包。
- macOS：Apple Silicon、Intel DMG。
- Linux x86_64：DEB 与 tar.gz；全局快捷键和 VV 需要 X11。
- QQ 输入法桥接 APK 沿用内部版本 `8.7.15-zsclip.8`，随桌面版本提供经过哈希核验的配套包。
- 提供 `SHA256SUMS.txt` 及自动更新清单；程序自动更新选择对应的 Windows 构建版本。

上述标签编辑、便签、可调窗口及原生设置界面功能适用于 Windows。macOS 全局输入和粘贴需要辅助功能与输入监控权限；超级邮件合并、WPS 任务窗格及图片贴图使用 Windows 集成。
