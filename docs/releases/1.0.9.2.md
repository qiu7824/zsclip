# ZSClip 1.0.9.2

Windows 维护版本，恢复 VV 选择粘贴。macOS、Linux 的功能补齐与目标平台验证纳入 1.0.10。

- 修复 VV 候选可以显示、选择后却不粘贴的问题，包括部分输入法的中文及英文状态。
- 输入法组合状态不可读取或无法取消时，仍向原输入目标粘贴；不发送通用 Esc，也不退格删除无法确认的输入内容。
- 修复选择失败后会话未结束、影响下一次 VV 触发的问题，覆盖文本、图片加载失败及目标失效的退出路径。
- 保留会话、焦点和内容保护检查，切换窗口或编辑区后取消过期粘贴。

已确认的英文触发串继续自动移除；无法确认输入状态时优先保留草稿，部分输入法可能保留触发字符。

Windows 提供普通版和无局域网版，设置与历史记录保持兼容。

QQ 输入法桥接包与桌面版配套提供，内部桥接版本为 `8.7.15-zsclip.8`，局域网连接需使用含同步功能的普通版。不再提供独立 Android 测试应用安装包。
