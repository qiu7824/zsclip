# ZSClip 1.0.9.1

## 输入与搜索

- VV 显示和取消不再向目标软件注入 Esc，完整处理取消按键的按下、重复和松开，取消过期候选与粘贴请求。
- 文件重命名粘贴遵循原生选区：仅替换选中内容，无选区时在光标处插入，支持撤销。
- 搜索输入变化立即淘汰旧请求，执行中的旧查询可中断；优化保护过滤、日期检索和查询排队，避免旧结果误回填。
- 查询失败显示错误并支持重试，文本悬停预览在后台加载，减少界面等待。

## 设置与列表

- 设置按常规、外观、剪贴板、快捷键与 VV、分组、插件、多端同步、关于八个分区组织。
- 内容字号提供默认及 12、14、16、18、20 档，覆盖列表、快速窗口、搜索与预览，适配显示器缩放。
- 外观页可选择卡片列表，并分别开启卡片边界和轻阴影，提供效果预览。
- 常用短语支持独立标题、标题与正文检索、单独重命名；分组页可关闭标题功能，关闭后保留已有标题数据。
- VV 支持不抢输入焦点的全文预览、悬停查看、键盘选择、滚轮与翻页。

## 复制粘贴与文件

- 本机富文本历史同时保存文字和必要 HTML 样式，普通粘贴恢复基本文字与表格样式；纯文本命令继续只粘贴文字。
- 相同文字的不同格式记录分别保留；编辑文字后清除过期格式，重命名短语不改变正文格式。
- “另存为 PNG”提供保存对话框，保存到选定位置，覆盖前确认，取消不创建文件。
- 提示音增加试听、播放结果提示和失败回退；复制与粘贴提示音独立控制，粘贴提示音用于 ZSClip 发起的粘贴。

## 兼容范围

富文本恢复以本机 HTML 表达的基本文字和表格样式为范围，不包含工作簿公式、宏、图表、嵌入对象或跨设备富文本同步。旧历史和配置继续可用，已关闭的富文本采集设置保持关闭。

Windows 提供普通版和无局域网版。macOS、Linux 与 Android 包维持测试版本定位。
