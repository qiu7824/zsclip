# ZSClip 1.0.12.1

## Windows：标签栏与高 DPI 显示

- 默认两个标签保持原有尺寸、圆角底色和选中样式，并整体居中。
- 标签增加时先适当压缩宽度，尽量在当前窗口内展示；空间仍不足时显示“更多”入口，当前选中的标签保持可见。
- “更多”菜单从按钮下方展开，便于连续切换标签。
- 分类标签、记录行快捷按钮和辅助对话框中的自绘文字、图标只按目标窗口 DPI 缩放一次，修复高缩放比例下的过大文字和图标。
- 绘制时明确使用窗口的布局 DPI，支持高、低 DPI 间切换，并在嵌套绘制结束后恢复原绘制环境，避免其他窗口的字号受到影响。

## Windows：标签与快捷按钮设置

- 分类标签、快捷按钮对话框按客户区计算尺寸，预留标题栏和边框，确保“确定”“取消”完整显示。
- 两列控件使用统一对齐与间距，底部加入分隔线。
- 列表行显示标签模式或按钮图标，以淡色标识手动、自动筛选和隐藏状态；选中行沿用设置页的高亮样式。
- 修改标签名称、内容方式和显示状态时，左侧列表立即更新。
- 快捷按钮设置增加顺序预览，直观显示删除、置顶、编辑按钮的显示状态与排列顺序。

## Windows：设置布局与暗色主题

- 调整设置卡片上下留白，标题区域分隔线与卡片列对齐。
- 外观预览展示列表边框、普通行和悬停行，可观察卡片、边框和阴影开关的实际效果。
- 改善暗色下拉框的边框、箭头和底色，减少浅色残留。
- 增加设置控件边界、紧凑标签排列以及 100%、125%、150%、200% 字体缩放回归检查。

## 数据与升级

- 手动标签仍默认为空，继续支持同一记录加入多个标签、批量加入或移出；移出或删除标签不删除原记录。
- 保留原有记录图标、普通列表默认值、窗口尺寸记忆和便签功能。
- 沿用现有数据格式，无需重新建立标签或迁移便签。
- 1.0.12 安装包保持原样；自动更新清单提供 1.0.12.1 对应的标准版及无局域网版安装包。

## 发布文件

提供 Windows x64 标准版、无局域网版安装包及便携包、资源包，macOS Apple Silicon 与 Intel DMG，Linux x86_64 DEB 与 tar.gz，以及配套 QQ 输入法桥接包、SHA-256 校验文件和自动更新清单。QQ 输入法内部版本仍为 `8.7.15-zsclip.8`。

上述界面改进适用于 Windows；Linux 全局快捷键和 VV 需要 X11，macOS 全局输入与粘贴需要辅助功能及输入监控权限。
