# ZSClip 1.0.13

## Windows：标签、窗口与设置

- 支持持久化手动标签，可改名、新增、删除、排序、隐藏，并将文本、网址、图片、文件和常用短语加入多个标签。
- 自动筛选标签与手动标签分开处理；切换标签、搜索、分页和新复制内容都遵循当前分类条件。
- 支持调整主窗口和快捷窗口的宽高并记忆尺寸；列表、标签、快捷按钮和设置页适配高 DPI。
- 完善标签栏、快捷按钮配置、暗色主题控件和设置布局，保留普通列表、记录图标及窗口状态。

## Windows：剪贴板、VV 与图片

- Windows VV 主窗使用双缓冲绘制，跨条目悬停和关闭窗口时保持稳定。
- 富文本剪贴板保留 Unicode 文本、制表符、空白格、换行和 HTML 格式；新记录预览不再显示 `HTML:` 前缀。
- 剪贴板读取繁忙时优先处理最新一次复制，序列号变化时终止旧读取，避免旧请求覆盖新内容。
- 外部程序复制、历史记录复制和粘贴流程按剪贴板序列号去重，避免程序自身写入被重复记录。
- 从资源管理器复制 JPEG 文件时生成图片缩略图和悬停预览。
- 跨权限自动粘贴受 Windows 阻止时提供手动 Ctrl+V 和用户确认后的 UAC 重启入口，默认不提权。

## Windows：启动与系统集成

- 全局快捷键占用时继续初始化托盘和剪贴板监听，并在快捷键恢复后自动重试注册。
- 快捷键冲突提供一次性提示，避免启动流程被占用的组合阻塞。
- 开机自启状态按当前程序路径及 Windows 启动项启用状态判断，切换后立即刷新，并清理失效的旧启动项。
- 便签插件支持本地多条便签、快捷键新建和自动保存；便签数据独立存储，不参与剪贴板同步。

## 同步、数据与 WebDAV

- WebDAV 备份按内容块增量上传，只传输发生变化的块，减少重复网络传输。
- 安装在受保护目录时，WebDAV 临时数据改用当前数据目录；凭据通过进程输入传递，不在程序目录生成认证临时文件。
- 支持在设置中更改数据目录，迁移时校验文件并保留原目录；不强制创建 D 盘目录。
- 局域网同步和 WebDAV 继续覆盖标准版与无局域网版的对应功能范围。

## 发布平台

- Windows x64 提供标准版、无局域网版、安装包和便携包。
- macOS 提供 Apple Silicon 与 Intel DMG；Linux x86_64 提供 DEB 与 tar.gz。
- 提供 SHA-256 校验文件、自动更新清单和配套 QQ 输入法桥接包；桥接包内部版本为 `8.7.15-zsclip.8`。
