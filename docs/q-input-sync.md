# QQ 输入法局域网连接

QQ 输入法通过普通局域网方案连接 ZSClip，无需独立的电脑版本或手机同步应用。

1. 电脑打开“设置 → 多端同步”，选择“局域网”。页面显示电脑地址、端口和连接权限。
2. 手机在输入法剪贴板中打开 ZSClip，点击“发现电脑”，选择电脑连接；也可填写电脑显示的地址。
3. 电脑收到连接请求后，核对设备名称、安全码并允许一次。
4. 在电脑和手机选择自动同步方向：手机 → 电脑、电脑 → 手机、双向或仅手动。自动收发同时受两端选项限制；仅手动时使用手机的发送、拉取或条目发送按钮。

新配置默认仅手动；已有配置升级保留原双向行为和设备配对。“手机内容”决定收到的内容仅进入电脑记录，还是同时覆盖电脑系统剪贴板。关闭自动收发仍会保留本机剪贴板记录。

## 连接权限

“刷新 / 修复连接”检查当前程序的 TCP 端口与 UDP 38472，处理 Windows 为本程序保存的本地拒绝连接规则。修复可能要求管理员确认；允许来源仅限本地子网。企业管理规则、手动阻止规则和其他程序规则保持原样，发现冲突时页面显示原因。

规则调整前保存在应用数据目录的 firewall-backups 中。手机亮屏解锁、输入法运行时可自动收取内容。

## QQ 云剪贴板

“设置 → 多端同步 → QQ 云剪贴板”提供导入手机授权、查看授权状态和撤销电脑授权。开启“右键显示上传 QQ 云剪贴板”后，可在文本记录的右键菜单手动上传。云上传与局域网方向独立，不自动下载云内容。

导入云授权需要手机已有合法有效登录态。QQ 客户端会拒绝该重签名包的快捷授权登录；输入法原生短信登录入口保留。需要接回原 QQ 输入法账号云数据时，应先在官方输入法的账号设置中绑定手机号。局域网配对与同步不需要 QQ 登录。电脑保存的授权有效时，可在手机不在线时独立上传选定文本。
