## 简介

#B站AI创造公开赛

参加 build in bilibili AI 创造公开赛。  
ZSClip 是我一直迭代的本地办公剪贴板增强工具，最早从 Python 小工具开始，后来为了常驻性能、系统集成和原生体验，把主力版本迁到 Rust，并开始做 Windows 纯原生 UI。

功能上支持复制记录、常用短语、组合搜索、右键分组、VV 模式、图片 OCR、文件素材化、WPS 任务窗格、WebDAV/局域网多端同步等能力。

这次视频重点演示功能使用、任务管理器里 0.1M 级别的常驻内存占用美学，以及我对 ZSUI 的后续设想：它不是另一个通用 UI 框架，也不是“一个人维护三平台 UI 框架”，而是一个 Rust 原生系统工具应用框架。核心方向是类型安全、显式、组合式、低魔法、可降级、少运行时反射、少全局状态；托盘、热键、弹窗、设置页、列表等能力会尽量写成明确合同，让 AI 和贡献者可以按合同补组件、补平台、补测试。

Windows 是当前主力版本。Android 已有初代 APK 和源码，iOS 先通过快捷指令做同步入口；macOS / Linux 原生 UI 目前是初代版本，还没有充分实机测试。感兴趣的小伙伴可以下载测试、加群反馈，我会第一时间修复。

后续更新方向：

- 搜索添加“附近”：查看命中记录前后时间线里的相关复制内容
- 分组添加“文件类型选项”
- 继续打磨 ZSUI：按合同补组件、补平台、补测试的 Rust 原生系统工具开放工程
