# QQ 输入法局域网桥接

桥接模块在 QQ 输入法原有剪贴板页面提供配对、手动发送及方向可选的局域网同步，并提供 QQ 云剪贴板授权入口。Android 包名保持 `com.tencent.qqpinyin`，私有连接页为 `com.zsclip.qqime.BridgeActivity`。

## 基包与源码

| 项目 | 值 |
| --- | --- |
| QQ 输入法基包版本 | 8.7.15 |
| 基包 SHA-256 | `8a89043aff22a11ee46a2d794e0e50cf6f1d80a29b4e8504fda728e02fb5bd2b` |
| Android 最低 API | 21 |
| Java 编译目标 | Java 8；Android SDK 35 |
| 桥接版本 | `integration.json` 的 `version_name` |

`src/main/java` 保存桥接代码，`src/test/java` 保存协议、方向和网络测试。`skin/assets` 对应基包的同名 assets 路径；`skin/vectors` 保存键帽矢量源，`skin/palette.json` 定义配色。

`integration.json` 的 `method_replacements` 仅替换指定方法中的设置图标资源名。`hooks` 指定 smali 文件、完整方法签名、插入位置和静态调用指令：输入法生命周期启停桥接；剪贴板长按菜单与详情页添加发送操作；工具栏资源刷新后归一设置图标；剪贴板面板、全屏页和云详情页注册视觉样式。插入前必须核对方法唯一性；重复构建不得重复注入。`before_return` 目标方法要求单一 `return-void`。

## 构建与签名

1. 校验基包 SHA-256，使用 apktool 解包到独立构建目录。保留基包的包名、版本码、原始资源 ID、原有类和本地库。
2. 按 `integration.json` 注入方法内 hooks 和资源名替换，设置 `versionName`；在 manifest 注册不导出的 `BridgeActivity`，使用 `@android:style/Theme.Material.Light.NoActionBar`。将 `skin/assets` 覆盖到解包目录中的对应已有文件。
3. 使用 apktool 重建宿主 APK。以 Android SDK 的 `android.jar` 为 bootclasspath，用 `javac -source 8 -target 8 -encoding UTF-8` 编译全部桥接 Java；打成 JAR 后使用 D8 的 `--min-api 21` 生成 DEX。
4. 将桥接 DEX 加入宿主 APK，名称为 `classes4.dex`。基包必须只有原来的三份 DEX；合并时移除原签名元数据。
5. 使用 `zipalign -P 16 -f 4` 对齐，再用 `apksigner sign` 签名；验证 v1/v2/v3 签名、签名证书、包名、版本和 `zipalign -c -P 16 4`。
6. 校验 ZIP、四份 DEX、全部 hooks 和覆盖资源；未列入覆盖清单的原始 assets 与本地库应与基包逐字节一致。APK 中不得包含 keystore、签名密码或授权数据。

覆盖更新已有桥接安装需要原来的私有签名密钥。密钥和密码应由构建环境单独保管，不能提交仓库；缺少密钥时应停止更新包构建，不能临时生成新密钥替代。该私有签名不同于腾讯官方签名。

## 连接与同步

电脑与手机连接同一局域网，电脑开启局域网同步。手机在桥接页面选择发现的电脑，或输入电脑 IP 与端口，在电脑核对配对码并确认。配对材料由 Android Keystore 保护。四种同步模式为仅手动、手机到电脑、电脑到手机和双向，实际方向取两端策略允许的交集。

长按半屏本地或云剪贴板条目可发送所选文本；本地全屏详情页也提供发送操作。操作读取当前选择项，保留原始空白和换行。手动发送和接收不改变自动同步方向；仅手动模式不监听系统剪贴板，也不轮询电脑。自动同步受输入法运行、屏幕与解锁状态、敏感内容规则及大小限制约束。

QQ 云剪贴板与局域网同步独立。云授权要求合法的输入法账号登录、已配对电脑、两端指纹核对及确认码确认。电脑保存授权后可以直接请求官方云服务。QQ 快捷 SSO 可能因 APK 签名不同被拒绝；官方短信登录入口保留，但账号会话及上传是否有效仍由官方服务决定。局域网同步不需要 QQ 登录。

## 视觉适配与验证

半屏菜单由宿主 `QQLinearLayout` 在测量时缩放。发送文字放在普通 `FrameLayout` 中，在自身测量时复制相邻菜单项最终的像素字号、字形、字距和字体内边距，避免重复缩放。菜单新增空间按文本测量宽度分配。本地详情动作采用原生时间标签的 13dp 字体度量。

`ToolbarIconStyle` 读取当前可见相邻工具键的 `ImageView` 布局、内边距和缩放方式，并以位图非透明区域归一设置图标的原生 Drawable 画布。它保留工具键触摸区域、图标状态和着色；宿主替换图片或改变尺寸后重新对齐。没有有效相邻位图时保持宿主显示。

`ClipboardVisualStyle` 只观察剪贴板页面，绘制前覆盖新绑定卡片与宿主后续配色。页面和普通卡片采用不透明白色、黑灰文字和浅灰边框；选中卡片以深灰轮廓区分，按下状态使用浅灰反馈。登录子树与按钮维持原生授权行为和样式。

验证范围包括 Android SDK 编译、原始 smali 调用关系检查、合成控件的多轮测量/重绘、动态列表绑定、图标透明边界与状态、手动选择项发送、APK 资源完整性、同证书签名及对齐。合成控件测试不能代替实机验证；横竖屏、键盘缩放、字体设置、真机配对及有效账号云授权仍需在获准的设备环境验证。
